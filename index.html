🧙 Bienvenido al Tasador MyL

Esta app usa IA para identificar tus cartas y buscar precios en tiendas chilenas.
Necesitas una API key gratuita de Groq para activar el reconocimiento por foto.

  1. 1 Entra a console.groq.com y crea una cuenta gratuita.
  2. 2 Ve a API Keys → Create API Key y copia la key generada.
  3. 3 Pégala aquí abajo. Se guarda solo en tu navegador, nunca la vemos nosotros.

🔒 La key se guarda en tu navegador (localStorage) y nunca sale de tu dispositivo.
Sin key, puedes buscar cartas escribiendo el nombre manualmente.
Límite gratuito de Groq: 14.400 requests/día con llama-3.2-11b-vision.
